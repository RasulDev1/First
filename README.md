# CRM для компании по установке вентиляции (шаблон)

Шаблон CRM на **Next.js 16 + TypeScript + Tailwind CSS 4**. Серверной части нет: данные хранятся в браузере (`localStorage`),
сайт собирается в статические файлы. Все данные в демо случайные: названия компаний, имена, адреса и телефоны вымышленные.
Название, логотип и реквизиты компании сюда не кладём.

## Как запустить

```
npm install
npm run dev        # разработка → http://localhost:3000
npm run build      # статическая сборка в папку out/ — её можно выложить на любой хостинг
npm run build:demo # сборка с относительными путями (демо-страница, открыть из любой папки)
npm run typecheck  # проверка типов TypeScript
```

Демо-аккаунты (пароль у всех `12345678`):

| Логин      | Должность              | Что видит |
|------------|------------------------|-----------|
| `director` | Руководитель           | Все разделы, сотрудники и роли, задачи менеджерам |
| `manager`  | Менеджер по продажам   | Заказы (мастера выбирает в заказе), клиенты, калькулятор, свои задачи, «Моя статистика» |
| `manager2` | Менеджер по продажам   | То же |
| `buyer`    | Закупщик               | Склад, заказы (только выписать материал) |
| `sklad`    | Складовщик             | Склад, заказы (только выписать материал) |
| `master`   | Мастер                 | Только «Мои заказы»: статус своих заказов и сколько заработает |
| `trainee`  | Стажёр                 | То же |

`/zayavka/` — форма заявки для сайта: клиент оставляет контакты, заказ появляется в CRM.

## Разделы

- **Заказы** — менеджер берёт заказ, выбирает мастера и дату выезда, ведёт статус
  (Создана → Назначен Мастер → Выезд на замеры → Согласование стоимости → В работе → Завершён / Отменён).
  Статус вручную не ставится, он меняется по действиям: менеджер назначил мастера → «Назначен Мастер»; мастер нажал «Выехал на замеры» (так записывается время выезда; дату выезда менеджер не вписывает), потом «Замеры сделаны» (менеджер видит это в карточке);
  менеджер сохранил замеры → «Согласование стоимости»; внесена оплата (окно «Внести оплату»: способ, сумма, «Оплатить») → «В работе»;
  мастер нажал «Завершён» → «Завершён». Назначенного мастера менять нельзя, пока он сам не откажется от заказа («Отказаться от заказа» в «Мои заказы»). Отмена и возврат заказа — только у руководителя,
  сумму договора; в карточке есть расходы со склада, оплата и история.
  Нижняя панель заказа: **Основное**, **Замеры** (только просмотр; данные с выезда вписываются в карточке заказа и сохраняются кнопкой «Сохранить», после чего остаются только во вкладке), **Смета**, Оплата, Расходы, История; переписка (комментарии) — внизу вкладки «Основное».
  Менеджер меняет только свои заказы: каждое изменение — с подтверждением. Руководитель правит любые.
- **Клиенты** — менеджер и руководитель: поиск по имени и номеру телефона, карточка клиента с историей заказов и кнопкой «Новый заказ».
- **Автосмета** — вкладка «Смета»: из замера считаются материалы (по складу, закупка + наценка 40%) и работы (прайс `WORKS` в `src/lib/config.ts`, цены ориентировочные,
  себестоимость работ пока 0). Четыре шага: замер → материалы → работы → итог. Внизу всегда видны итог, прибыль и процент (прибыль / цена).
  Нижний порог маржи 25%: менеджер не может поставить цену строки или сумму договора ниже «закупка / (1 − порог)», руководитель порог меняет и может цену опустить.
- **Калькулятор** — менеджер и руководитель: тип системы (приточная, вытяжная, с рекуперацией, кондиционер), площадь, число помещений, высота и кратность воздухообмена →
  материалы по складу, работы по прайсу, итог с вилкой ±10%, прибыль и процент. Считает тем же расчётом, что автосмета.
- **Мастера** — два типа: мастер и стажёр. Контакты, загрузка, ближайшие выезды, выполненные заказы и комментарии о мастере. Добавляет мастера, задаёт его зарплату (% от суммы заказа), логин и пароль только руководитель.
- **Мои заказы** — раздел мастера и стажёра: только свои заказы со статусом и тем, сколько мастер заработает в этом месяце; кнопки «Выехал на замеры», «Замеры сделаны» и «Завершён».
- **Задачи** — ставит только руководитель, менеджер видит свои и отмечает выполнение; у каждой задачи есть переписка. Руководитель привязывает задачу к любому заказу: из списка или номером вручную.
- **Склад** — остатки по местам, карта склада, кнопки «Приём» и «Расход», перемещение, списание, пересчёт,
  список закупки и журнал движений. «Расход» выписывает материал с места на заказ, он попадает в колонку «Расходы»
  этого заказа (по себестоимости). Складовщик и закупщик видят вкладки заказа «Замеры», «Смета» и «Оплата» только для просмотра и выписывают материал.
- **Моя статистика** — раздел менеджера: оформленные им заказы и их сумма, кнопка «Зарплата» с разбивкой по причинам
  (оклад, процент от продаж, за каждый завершённый заказ, за повторных клиентов, за выполнение плана, за месяц без отказов;
  размеры в `src/lib/bonus.ts`).
- **Аналитика** — только у руководителя: заказы и продажи по неделям, источники, услуги, мастера, менеджеры. Руководитель дополнительно видит
  расход на материалы, закупленный товар (что и на какую сумму принято на склад), зарплаты мастеров и **чистую выручку** (продажи − материалы − зарплаты), а также стоимость склада.
- **Сотрудники** — руководитель добавляет сотрудников, меняет должность и пароль, отключает доступ.

## Места на складе

3 линии × 6 стеллажей × 3 полки = 54 места. Место пишется как `линия-стеллаж-полка`: линия — буква, стеллаж и полка — цифры.
Например, `А-1-2` — линия А, первый стеллаж, вторая полка.
Размер склада и названия меняются в `src/lib/config.ts`.

## Где хранятся данные

Демо хранит данные в браузере (`localStorage`). Кнопка «Сбросить демо» возвращает исходные случайные данные.

## Файлы

- `src/app/` — страницы Next.js: `page.tsx` (CRM), `zayavka/` (форма заявки), `globals.css` (цвета и шрифты Tailwind)
- `src/components/` — каркас: вход и меню (`crm-app.tsx`), кнопки, поля и таблицы (`ui.tsx`), выезжающая панель, уведомления, логотип
- `src/views/` — разделы CRM; `src/views/requests/` — карточка заказа, замеры, автосмета
- `src/lib/` — логика без интерфейса: `types.ts` (таблицы), `db.ts` (хранилище), `seed.ts` (демо-данные), `config.ts` (настройки),
  `auth.ts` (роли), `orders.ts` (статусы), `estimate.ts` (автосмета), `survey.ts` (замеры), `stock.ts` (склад), `pay.ts`, `bonus.ts`, `clients.ts`
- `public/img/mark.svg` — логотип
